# ♻️ خبير إعادة التدوير والاستدامة الذكي (V3.0)
### Smart Recycling Project Advisor & Carbon Offset Engine

منصة ذكية متكاملة تعتمد على الذكاء الاصطناعي (Google Gemini) لتحليل المواد والمخلفات المنزلية وابتكار مشاريع إعادة تدوير عملية مع معرض صور ثلاثي الأبعاد واحتساب الوفر الكربوني وفق معايير تقييم دورة الحياة الدولية (ISO 14044).

---

## 🌟 الميزات الرئيسية (Key Features)

- **🤖 توليد مشاريع حصرية بالذكاء الاصطناعي (Live AI Synthesis):** تحليل المواد المدخلة من المستخدم (زجاج، خشب، علب ألمنيوم، بلاستيك، كرتون، أقمشة...) وتوليد مشاريع حقيقية مخصصة ومطابقة 100% للمواد.
- **🎨 معرض صور ثلاثي لكل مشروع (Multi-Image AI Showcase):**
  1. **المشهد الأول:** صورة المنتج النهائي المكتمل (Finished View).
  2. **المشهد الثاني:** مخطط ورشة العمل ومراحل القص والتجميع (Assembly View).
  3. **المشهد الثالث:** لقطة واقعية للمنتج أثناء الاستخدام المنزلي والديكوري (Lifestyle View).
- **🔬 مصفوفة الهندسة والتوافق الكيميائي (Engineering & Bonding Matrix):**
  - مؤشر قابلية التنفيذ المنزلي (Feasibility Score).
  - تقدير العمر التشغيلي (Durability Index).
  - احتساب الوفر المالي التقديري (Economic ROI).
  - دليل المواد اللاصقة وأدوات السلامة وتقنيات التشكيل.
- **🛠️ نمط التنفيذ التفاعلي (Interactive Checklist Mode):** بطاقات تتبع متسلسلة مع مربعات تحقق ونظام مكافأة النقاط البيئية (+5 نقاط لكل خطوة).
- **💬 مستشار الذكاء الاصطناعي المتخصص (Context-Aware Assistant):** استشارة فورية ترتبط بسياق وتفاصيل المشروع المختار مباشرة.
- **📜 شهادة اعتماد الوفر الكربوني الرسمية (ISO 14044):** توثيق رسمي قابل للطباعة والتصدير يتضمن الصورة الفائزة، البصمة الكربونية الموفرة، وأكواد الاعتماد المشفرة.

## 🧠 محرك الأفكار المتقدم (OpenRouter)

يعمل التوليد على مرحلتين:
1. **عصف ذهني:** 8 أفكار مختلفة جذرياً، كل فكرة مقيّمة (إبهار، ابتكار، فائدة، قابلية تنفيذ)، ثم يُختار أقوى 3 بأنماط مختلفة.
2. **تطوير:** دليل تنفيذ كامل لكل مشروع (6–9 مراحل بقياسات دقيقة، نقطة تحقق لكل مرحلة، حلول للأخطاء الشائعة، تطويرات مقترحة)، مع تحقق آلي وإصلاح تلقائي إن نقص شيء.
3. **صور:** صورة رئيسية + صورة لكل مرحلة تُولَّد بالذكاء الاصطناعي بنفس "هوية بصرية" ثابتة للمنتج، وتُخزَّن في IndexedDB.

### الإعداد
مفتاح OpenRouter يبقى على الخادم فقط:

```bash
# تطوير محلي: ملف .env.local (لا يُرفع إلى git)
echo "OPENROUTER_API_KEY=sk-or-v1-..." > .env.local
npm run dev

# الإنتاج: دالة Supabase
supabase secrets set OPENROUTER_API_KEY=sk-or-v1-...
supabase functions deploy ai-gateway
```

حدّد حداً للإنفاق على المفتاح من لوحة OpenRouter لأن الدالة عامة. النماذج قابلة للتغيير عبر المتغيرات `OPENROUTER_*_MODEL` (انظر `.env.example`).

## 🖼️ الصور عند الطلب، الضغط، ولوحة التحكم

- **الصور**: لا تُولَّد أي صورة تلقائياً. بعد توليد المشروع، افتح صفحته واضغط «توليد صورة المشروع بدقة عالية» (2K)، أو «توليد صورة هذه المرحلة» لكل خطوة. تُحفظ الصور في متصفحك ويمكن تحميلها.
- **الضغط والرصيد**: عدد المشاريع يقلّ تلقائياً 3 ← 2 ← 1 ثم يتوقف، حسب عدد العمليات الجارية ورصيد OpenRouter المتبقي. تتوقف الصور أولاً عند قلة الرصيد. لكل شخص حدود يومية.
- **لوحة التحكم**: تظهر فقط للحساب `ADMIN_EMAIL` بعد تحقق الخادم من رمز Supabase (لا يكفي تعديل المتصفح). تعرض مدة التشغيل، المشاريع المتبقية بالرصيد، الزيارات الأخيرة، وكل المشاريع المنتجة.
- **النشر**: شغّل القسم 4 من `supabase/schema.sql` في Supabase SQL Editor، ثم `supabase functions deploy ai-gateway` وضع الأسرار (`OPENROUTER_API_KEY`, `ADMIN_EMAIL` …). ضع حد صرف على مفتاح OpenRouter ليعرف الخادم الرصيد.
